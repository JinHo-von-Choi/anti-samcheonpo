# Codex 계측·평가 개선 구현

2026-10-21, 기준 커밋 `4b490d641429a98ec85d1d5e5a932a52368de927` 이후 작업 트리.

계측 결함과 후보 효과 판정의 과장 가능성을 수정했다. 실제 Codex 실행과 자동 검사는 아래 범위로 검증했다. Codex 사용자의 완료율·비용 개선은 아직 입증되지 않았다.

## 변경

- 종료 코드가 없으면 미확인으로 남긴다. 기존 실패를 기본값 0으로 덮지 않는다. `Execution`에 상태·호출 ID·프로세스 ID·결과 출처·시각·원본 해시를 기록한다. 명시적 종료 코드와 실행 출력은 구분한다.
- legacy `exec_command → write_stdin`은 원래 명령을 갱신한다. poll마다 명령·검사 수를 늘리지 않는다. 현대 rollout은 기존 item 우선 경로를 유지해 코드 모드 wrapper 중복을 피한다.
- 늦은 rollout 결과와 중복 PostToolUse는 기존 사건 및 원장 행을 갱신한다. 탐지기에 명령을 다시 관측시키거나 과거의 성공 스냅샷을 소급 생성하지 않는다. 결과 수신과 훅 처리 여부를 별도로 추적한다.
- 실행 상태는 원장 재열기·분석 스냅샷에도 보존한다. 복원된 호출에 늦은 결과를 연결할 수 있다.
- 관측 모델을 실시간 세션 요약에 전달한다. 혼합 모델 사용량은 `<mixed>`로 표시해 첫 모델 단가로 합산하지 않는다. 재개 이전 사용량과 중복 누적 기록은 다시 청구하지 않는다.
- `gpt-6-astra` Standard API 등가 단가를 확인일 2026-10-21부터 추가했다. 입력/출력/캐시 읽기/캐시 쓰기는 각각 $10/$50/$1/$12.50 per 1M이다. 과거 기록에 소급하지 않는다. [공식 모델 가격](https://developers.openai.com/api/docs/models/gpt-6-astra), [공식 가격표](https://developers.openai.com/api/docs/pricing).
- `bench probe` v2는 결과 건수(`outcome`), 효율(`efficiency`), 증거 충분성(`evidence_sufficient`)을 분리한다. 기존 과제군 단위 bootstrap을 재사용하고, 완료율 차이 하한 ≥ -0.02 및 완료당 총비용 절감 하한 ≥ 0.15를 함께 충족해야 `helped`를 낸다. 실패 시행과 감시 비용도 포함한다.
- 중복 시행, 짝 없는 시행, 과제군 불일치, 모델·실행 조건 변경, 검출된 채점기 오염은 비교를 거절한다. 독립 과제군 12개·짝 시행 30개 미만과 퇴화 신뢰구간은 효율 판정 근거로 사용하지 않는다.
- 증거 digest는 비용·시간·오염·과제군·관측 모델·조건을 포함한 전체 시행 행을 묶는다. verdict digest에는 산출물 수와 새 판정 필드도 포함한다.
- shadow 모드에서 초안 요청과 압축 후 안내가 새어 나오는 경로를 막았다. 사용자가 명시한 보호 경계는 유지한다. 따라서 보호 규칙이 있는 shadow는 완전한 무개입 대조군과 구분해야 한다.

## 실험 조건 기록

`bench ab` 설정의 각 arm에 `conditions`를 넣으면 시행 결과에 복사된다. timeout은 실제 task/실행 설정 값으로 기록된다. 나머지는 실행자가 검토한 manifest이며 런타임 자동 증명이 아니다. 비밀값 대신 지시·스킬·MCP manifest의 digest를 기록한다.

```yaml
conditions:
  reasoning_effort: "현재 실행에서 확인한 값"
  instructions_sha256: "공통 AGENTS 지시 manifest SHA-256"
  skills_sha256: "사용 가능한 스킬 manifest SHA-256"
  sandbox: "현재 실행에서 확인한 값"
  network: "현재 실행에서 확인한 값"
  mcp_sha256: "비밀값을 제외한 MCP manifest SHA-256"
  cache_policy: "natural-warm; 순서 무작위화"
```

빈 조건, 관측 모델 누락, 오염 검사 누락은 효율 개선 판정을 보류한다. 과거 protocol 2 행은 계속 읽지만 새 판정에 필요한 근거가 없다는 사실을 함께 출력한다. `outcome=helped`는 통과 건수가 늘었다는 기술 통계이며, 최상위 `verdict=helped`와 다르다. 이 명령은 규칙을 자동 승격하지 않는다.

정적 비교군 C에 사용할 [최소 지침](../../bench/guidance/codex-minimal.txt)을 작성했다. 자동으로 사용자 지시에 설치하지 않는다. 기존 동일 검사 반복 탐지와 재검사 허용 경로를 재사용한다. 범위 포함 관계를 추론하는 새 탐지 규칙은 대조 실험 뒤 결정한다.

## 실제 실행

기존 모델·권한·인증·연결 설정을 덮어쓰지 않은 임시 작업 폴더에서 Codex CLI 0.163.0, 관측 모델 `gpt-6-astra`를 실행했다.

- 계산기 `add` 오류 수정 후 `python3 test_calc.py`가 통과했다. 실행 종료 뒤 별도 프로세스로 같은 검사를 재실행해 exit 0을 확인했다.
- 출력 없는 `sys.exit(7)`은 exit 7로 기록됐다.
- 지연 명령은 정상 완료했다. 통신 poll 동작은 별도의 legacy 회귀 검사에서 검증한다.
- 원본 rollout의 명령 5건은 `[0, 0, 0, 7, 0]`, 총 사용량은 169,674토큰(입력 168,944 안에 캐시 읽기 131,456 포함, 출력 730)이었다.
- [비식별 fixture](../../testdata/codex/captured-0.163.0.jsonl)는 명령문·출력·경로·ID를 제거하고 native 구조·상태·종료 코드·토큰을 보존했다. 새 파서로 명령 수와 토큰 합계를 대조한다.

이 실행은 계측 smoke 한 건이다. 실행 중 사용된 설치판 감시기는 작업 트리의 새 데몬이 아니며, 새 데몬의 결과 반영은 별도의 실제 SQLite 통합 검사로 검증한다. 효과 크기·평균 비용·정밀도·재현율을 이 실행으로 추정하지 않는다.

## 검증과 남은 조건

최종 결과는 [평가 증거 JSON](2026-10-21-codex-implementation.json)에 기록했다. `go test -count=1 -json ./...`에서 49개 패키지와 942개 테스트 항목(하위 사례 포함)이 통과했다. 처음 건너뛴 `TestCleanEnvironmentBinarySmoke`는 두 실행 파일을 빌드한 뒤 별도로 통과했다. 과제별 timeout 비교를 보완한 뒤 bench 패키지도 다시 통과했다. Codex·shadow 관련 `-race` 검사와 최초 결함 재현 3건도 통과했다. 중간 실패 로그와 수정 후 로그의 해시를 함께 보존했다.

기술적으로 남은 제약은 다음과 같다.

- 새 가격은 Standard API 등가 추정이다. Fast/Batch, 272K 초과 요청 할증, 구독의 실제 결제액을 반영한 청구 금액이 아니다. 현재 환율 테이블도 실시간 환율이 아니다.
- rollout 누적 사용량 자체가 리셋되거나 모델 변경 경계를 넘어 지연 보고되는 경우의 정확한 요청별 귀속은 추가 원본 자료가 필요하다. 혼합 집계는 미가격 처리하지만 이를 완전한 청구 복원으로 해석하지 않는다.
- 후속 명령이 이미 실행된 뒤 도착한 종료 결과는 저장 사실을 바로잡지만 과거 개입을 다시 전달하지 않는다.
- 실행 조건 manifest의 실제 적용 확인, 오염 탐지의 완전성, live hook 처리량·지연의 운영 검증은 별도다.
- 사람 라벨·실행 파생 라벨 분리는 기존 구현을 사용한다. 이번 작업에서 사람 라벨을 생성하거나 대체하지 않았다.

후속 본 실험은 A 기본 Codex / B 기록 전용 / C 최소 정적 지침 / D 현재 정책을 독립 원본 과제군과 반복 시행으로 비교해야 한다. 위 smoke는 네 군 비교가 아니다. 이후 같은 날 runner에 명시적 `monitor_rollout: default`를 추가하고 제품 기본 정책의 격리 실행을 지원했다. 후속 실행과 한계는 [4군 파일럿 평가](2026-10-21-codex-pilot.md)에 별도 기록한다. 공개·생성 과제만으로 비공개 holdout을 주장하지 않는다. 실사용 과제군·독립 검토자 2인·비개발자 참여자 자료가 아직 없어 본 실험과 제품 효과 판정은 미완료다. 신규 개입의 기본 승격도 하지 않았다.
