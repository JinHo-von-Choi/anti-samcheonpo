# 인수인계 묶음 v1 초안

`samcheonpo handoff <세션> --format json`은 목표 이력·근거·실패·복구·세션 관계를 담은 로컬 JSON을 출력한다. `--format text`는 사람이 읽을 요약과 실행하지 않은 시작 명령을 출력한다. JSON에는 원문 목표와 경로·검사 명령·로컬 기록이 들어갈 수 있다. 공유용 비식별 자료가 아니며 자동 업로드하지 않는다.

## 포함하는 정보

- `handoff/1` 버전, 생성 시각, 원본 에이전트/세션.
- 작업 ID와 연속된 사용자 의도 개정, 각 요청의 세션·이벤트 출처.
- 최신 개정의 목표와 검사 해시에 모두 일치하는 현재 계약. 다른 경로·다른 목표의 계약을 붙이지 않는다.
- 현재 개정의 검증 근거: 원본 세션·검사 결과 출처, 명령/입력/환경/러너 지문, 관측·만료 시각, 완전성·부작용·flaky 상태.
- 원장에서 실제 비정상 종료 코드가 관측된 최신 20개 실행. 실행하지 않은 차단(`-1`)을 실패한 시도로 세지 않는다. 명령 원문 대신 저장된 요약·명령 지문·결과 지문을 보존한다.
- 제안·전달·응답·효과 관찰 상태가 구분된 복구 기록과 종료 조건.
- 명시적으로 기록한 부모·자식 세션 관계와 세션별 계측분. 실제 청구액·절감액은 포함하지 않는다.
- 관측 누락 수와 미확인 사항. 작업 원장이 없는 이전 세션은 작업 정체성을 만들어내지 않는다.

## 수신 경계

`samcheonpo handoff inspect bundle.json`은 최대 4MiB의 알려진 버전만 읽고, 검사 명령을 실행하거나 계약을 수락하지 않는다. 원본 JSON의 키만으로 과거 통과를 현재 통과로 올리지 않는다.

`--verify-inputs`는 수신 경로에서 같은 목표·검사 계약이 이미 별도로 수락된 경우에만 로컬 입력·환경 지문을 읽는다. 검사 명령은 실행하지 않는다. 원본 근거 전체가 수신 측 원장에 동일하게 존재해야 재사용 후보의 현재 일치를 판정한다. 새로운 머신에서 받은 JSON만으로는 진위를 확인할 수 없으므로 후보 상태를 유지한다. 파일·환경·개정·명령이 다르거나 근거가 만료되면 재사용을 인정하지 않는다. 관측 누락은 재사용을 중단한다. 수동 조건은 항상 별도 확인이다.

이 검사는 로컬 원장의 신뢰를 전제한다. 사용자 신원 인증이나 원격 서명 검증을 제공하는 규격이 아니다. 메타데이터·원문은 실행 지시가 아닌 역사적 자료로 취급한다.

## 작업 연결과 계측분 합산

```sh
samcheonpo handoff link <부모세션> --from claude --agent codex --session <새세션>
```

기존 작업으로 새 세션을 명시적으로 연결한다. 부모가 없거나 다른 작업에 연결됐거나 동일 세션의 관계를 바꾸려는 요청은 거절한다. 다음 세션 시작/재시작에서 목표 개정을 복구하며, 실행 중인 다른 세션의 목표·권한은 바꾸지 않는다. 별도 경로에서 복구하려면 프로젝트 정체성 문제를 먼저 해결해야 한다. 현재 프로젝트 ID는 정규화 경로에 묶여 있어 다른 머신/경로로의 자동 연결을 지원하지 않는다.

`--includes-children`은 **새로 연결하는 세션**의 계측에 자손이 포함된다는 명시적 선언이다. 합산은 연결된 단일 루트와 모든 부모를 요구한다. 상위 세션이 자손 포함을 선언하면 해당 자손은 합계에서 제외한다. 동일 세션의 같은 스냅샷 재전달은 중복 계산하지 않고, 값이 충돌하면 합계를 미확정으로 남긴다. 여러 루트·누락된 부모·순환·음수·정수 범위 초과를 조용히 더하지 않는다. 토큰 또는 단가가 없으면 해당 항목은 `null`이다.

포함 관계는 저장된 선언이지 공급자의 회계가 정확하다는 인증이 아니다. 출력 합계는 연결 기록의 **계측분**이며 관측되지 않은 사용량까지 포함한 총사용량을 주장하지 않는다. 기존 원장의 세션 ID가 다른 에이전트와 충돌하면 그 사용량을 가져오지 않는다. 현재 v1 세션 원장은 전역 세션 ID를 사용하므로 충돌하는 라이브 세션 시작·저장도 거절한다. 이 경우 서로 다른 세션 ID를 써야 하며, 서로 다른 에이전트라는 이유만으로 같은 ID의 기존 기록을 덮어쓰지 않는다.

검증: 작업 키·실제 세션 출처를 사용한 근거 저장, 후속 의도 개정의 이전 통과 무효화, 새 에이전트의 목표 복구와 초안 실행 금지, JSON 출처 변조와 환경 변경의 재사용 거부, 실행 명령을 넣은 묶음의 비실행 검사, 포함 부모·정확 재전달·미확인 부모·충돌 스냅샷·단가 누락 검사를 수행했다. 격리된 실제 실행 파일에서도 Claude 훅으로 생성한 목표를 JSON으로 내보내 읽고, Codex 세션 ID로 연결·시작한 뒤 같은 작업 ID/개정/원래 출처와 초안 미승인 상태를 확인했다. 실제 모델 호출이나 제품 효과 실험은 아니다.
