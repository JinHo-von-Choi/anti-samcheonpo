## 2026-10-13 실행 증거

- 독립 UID에서 최신 전체 `go test ./...` 통과(live 29.143초), `go test -race ./...` 통과(live 194.034초), `go vet ./...` 통과. Go 파일·모듈 439개가 원본과 일치한 사본에서 실행했다(SHA-256 ad165ae0bd751b034444f2d859891cf7636c06e4db30254549e6eb08c1858620). 원본 검토 보호·부정 요청·감시 빌드 지정·전체 시간/토큰·CLI 전체 검토 보호까지 포함한다.
- Claude/Codex 실제 형식 적용/정상/허용 목/미적용 편집 등 conformance 32/32 통과.
- 실제 프로세스 훅 200/200 응답·도구 수신, 시간 초과/실패/누락 0, 최종 처리 p95 2.041ms(6ms 게이트 통과), 프로세스 포함 p95 8.677ms. 별도 최초 콜드 스타트 89.436ms에서는 응답 시간 초과가 있었고 요청 기록은 확인됨; warm 200회에 섞어 0건으로 표시하지 않음.
- 최신 화면 데스크톱·390px 모바일 가로 넘침 없음, 판정 숨김, 로그인·고정 구간 선택·0600 신고 저장, JS 오류 0. 브라우저 자동시험 라벨은 실제 사람 라벨이 아니다.
- 실제 검토 큐: 후보 200/미검토 대조 400, Claude 361/Codex 234/Hermes 4/OpenCode 1. 사람 정답 0, 전체 600구간 합의 미확인. 원본 해시 561개 중 520개 이벤트 순서 일치·41개 불일치·39개 원본 미고정. 참조 휴리스틱과 최신 규칙 재생을 함께 실행했다(reference-comparison/2). 최신 재생에서 68구간에 후보가 관측됐지만 사람 정답이 없어 정확도는 미확인이다. 참조 휴리스틱은 SDK 원본 실행이 아니며 외부 솔루션 대비 우월성 인수는 미완료.
- 실제 기본 권한의 예비 모델 시험: Claude Write 거절로 독립 grader 실패, Codex 90초 시간 초과. 완료/절감 효과로 계산하지 않는다. 임시 평가 폴더에서 편집·지정 검사를 허용하는 변경은 별도 사용자 응답이 아직 필요하다. 전역 권한·모델·인증은 변경하지 않았다.

- Cursor 실제 버전 2026.09.02-c22c1a3의 기본 권한 읽기/관측 훅 시험은 인증 미비로 시작 실패. Copilot CLI 1.0.95는 OS 파일 감시 한도로 시작 실패. 자체 시험 브라우저 정리 후 Copilot 재시도에서도 같은 감시 한도 오류. 실제 훅 수신 둘 다 0건이며 전역 인증/감시 설정과 지원 능력 표를 변경하지 않음.

전체 플랜은 미완료다. 실제 두 사람 정답, 실제 회복/효과 실험, 조건부 플랫폼 연결 인수와 실제 적용을 시험 통과로 대체하지 않는다.

실험 연결 보강: `monitor_executable`로 시험할 빌드를 지정하면 원본 바이너리와 단계 설정을 SHA-256으로 고정한 사본을 시행별 홈에서 기동한다. shadow/recommend는 일반 상승 차단 0회이며, 신규 선택은 `recommend_rules`의 advisory 전용 규칙만 허용한다. 2026-10-21 추가된 명시적 `monitor_rollout: default`는 제한 상승을 포함한 제품 기본 설정을 사용하고 실험 규칙·팩 추가를 거절한다. 준비 응답과 종료·원장 확정, 실제 에이전트 세션의 사건 수신을 확인한다. 모델/인증/네이티브 권한은 변경하지 않는다. 총시간은 준비·실행·독립 채점·감시 종료를 포함하며, 완료당 토큰은 실패 시행과 감시 API를 포함한다. 감시 토큰이 빠지면 총토큰은 미확인이고, 금액만 미확인일 때 이미 관측한 토큰은 별도로 유지한다. 시간 초과 시행은 최종 사용량이 빠질 수 있어 완전한 비용·토큰 합계로 사용하지 않는다.

라벨 보강: CLI도 원장을 읽기 전용으로 열고, 탐지 비용 분류를 기본 검토 출력에서 숨긴다. 일부 쪽을 본 뒤 종료한 기록은 전체 검토가 아니다. 모든 쪽을 표시하고 `reviewed yes`를 명시해야 전체 검토로 기록한다. 새 파일 이름은 세션 ID의 안전한 인코딩을 사용하고 기존 안전한 파일은 보존한다. GUI는 기존 CLI 파일에 같은 검토자의 동일 구간이 있으면 중복을 거절한다. 큰 라벨 행의 파싱 유실도 오류로 보고한다.


## 검토 저장·비교 평가 추가 보강

- 웹 서버 간 및 CLI/웹 간 같은 프로세스 외부 저장 경합을 OS 파일 잠금으로 보호한다. 소유 프로세스 종료 시 잠금이 풀리고, 원자적 0600 파일 교체로 독자가 부분 JSONL 행을 보지 않는다. CLI에서 검토 시작 후 파일이 바뀌면 오래된 저장을 거절한다. 서로 다른 파일 이름에 같은 검토자·구간 답변을 저장하는 것도 거절한다.
- 검토 답변에 원장 지문과 고정 큐 지문을 저장한다. 웹 고정 큐와 CLI `label --queue`는 구간·원장·고정 원본을 확인한다. 비교 평가는 양쪽 지문이 일치하는 답변만 정답 후보로 사용한다. 기존 수동 라벨을 자동으로 고정 자료의 정답으로 변환하지 않는다.
- `reference-comparison/3`는 같은 합의·관측 가능 구간에서 각 비교기의 혼동 행렬·precision/recall·Wilson 95% 구간을 계산한다. 검토 불일치/정답 부재와 예측 근거 부재는 별도로 공개하고, 분모가 없으면 null이다. 검토 구간 이후의 이벤트는 입력에서 제외한다. 이 기술 통계는 층화 표본의 모집단 정확도나 실사용 효과·출시 인수를 입증하지 않는다.
- 이번 변경의 관련 전체 패키지 `go test -race ./internal/eval ./internal/dashboard ./internal/cli` 통과(eval 4.490초/dashboard 2.615초/cli 14.128초), 해당 패키지 `go vet` 통과. 별도 프로세스 경합·프로세스 종료 후 해제·CLI 오래된 저장/별도 파일 중복·두 웹 서버 경합·원본/큐 불일치 답변 제외·공통 분모/분모 없음·미래 이벤트 배제 회귀를 포함한다. 위 439개 파일의 전체 시험 기록은 이 추가 변경 이전의 검증 기록이다.

최종 빌드로 실제 600구간을 재실행한 결과: reference-comparison/3, 원본 순서 검증 520/불일치 41/미고정 39, 재생 후보 구간 68, 실제 사람 라벨 0. 공통 평가 구간은 0이며 세 비교기의 precision/recall 및 CI는 null이다. 예측 근거 유보는 최신 규칙 165/동일 호출 휴리스틱 290/편집 횟수 휴리스틱 80구간이다. 이 숫자는 정상·양성 정답 수가 아니다. 비식별 최종 집계는 [실제 자료 요약](../benchmarks/2026-10-13-real-review-summary.json)에 보관했다.
