# solve(req) 금액 배분 규칙

입력은 `{"total": 정수 센트, "weights": [0 이상의 정수, ...]}`이다. |total|은 10^9 이하, 각 weight는 10^6 이하다.

1. weights가 비었거나 합 W가 0이면 `null`을 반환한다.
2. T = |total|로 계산한 뒤 total이 음수면 모든 몫의 부호를 뒤집는다. 0은 0으로 둔다.
3. 각 몫의 기본값은 floor(T × w_i / W)다. 기본값 합과 T의 차이 R만큼, 나머지 (T × w_i) mod W가 큰 순서로 1센트씩 더한다. 나머지가 같으면 인덱스가 작은 쪽이 먼저다.
4. 반환값은 weights와 같은 길이의 정수 배열이며 합은 정확히 total이다. 입력 객체를 바꾸지 않는다.
