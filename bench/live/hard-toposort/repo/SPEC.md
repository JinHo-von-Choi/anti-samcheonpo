# solve(req) 의존성 순서 규칙

입력은 `{"nodes": [고유 문자열, ...], "edges": [[a, b], ...]}`이다. `[a, b]`는 a가 b보다 먼저라는 뜻이며, edges의 노드는 모두 nodes에 있다. 같은 간선이 여러 번 나오면 한 번으로 본다.

1. 순환이 없으면 `{"order": [...]}`를 반환한다. 선행 노드가 모두 나온 노드 중 문자열 비교로 가장 작은 노드를 매번 고른다.
2. 순환이 있으면 `{"cycle": [...]}`를 반환한다. 목록은 방향 순환 위에 있는 노드(자기 자신으로 가는 간선 포함)만 담고 문자열 오름차순이다. 순환에서 나가는 간선으로만 도달하는 노드는 넣지 않는다.
3. 입력 객체를 바꾸지 않는다.
