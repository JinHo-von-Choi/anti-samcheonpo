# solve(req) 줄바꿈 규칙

입력은 `{"text": 문자열, "width": 정수}`이며 width는 2 이상이다. 반환값은 줄 문자열의 리스트다.

1. 글자 폭: `unicodedata.combining(c)`가 0이 아니면 0, `unicodedata.east_asian_width(c)`가 `W` 또는 `F`이면 2, 그 밖은 1이다.
2. text를 `"\n"`으로 나눈 각 문단을 따로 줄바꿈한다. 단어가 없는 문단(빈 문자열이나 공백만 있는 문단)은 빈 줄 `""` 하나가 된다.
3. 단어는 공백(`" "`)이 아닌 글자의 최대 연속 구간이다. 하이픈 등 다른 글자에서는 나누지 않는다. 출력 줄은 단어를 공백 하나로 잇고 앞뒤 공백이 없다.
4. 현재 줄이 비어 있으면 단어 폭, 비어 있지 않으면 현재 폭 + 1 + 단어 폭이 width 이하일 때 단어를 현재 줄에 붙인다. 아니면 현재 줄을 내보내고 새 줄을 시작한다.
5. 단어 폭이 width보다 크면, 현재 줄이 비어 있지 않을 때 먼저 내보낸다. 그다음 단어를 앞에서부터 글자 단위로 채워, 다음 글자를 더하면 width를 넘을 때 조각을 내보낸다. 폭 0 글자는 언제나 앞 조각에 붙는다. 마지막 조각은 현재 줄이 되어 뒤 단어가 4번 규칙으로 이어 붙을 수 있다.
6. 문단 끝에서 현재 줄이 비어 있지 않으면 내보낸다.
