# solve(req) 설정 병합 규칙

입력은 `{"base": 객체, "override": 객체}`이고 값은 JSON 값이다. 반환값은 병합한 새 객체다.

1. 결과는 base의 깊은 복사에서 시작한다. base와 override는 바꾸지 않는다.
2. override의 각 키를 차례로 적용한다. 키가 `__proto__`, `constructor`, `prototype`이면 무시한다.
3. 값이 `null`이면 결과에서 그 키를 지운다(없으면 아무것도 하지 않는다).
4. 결과의 기존 값과 새 값이 모두 배열이 아닌 객체면 같은 규칙으로 재귀 병합한다.
5. 그 밖에는 새 값의 깊은 복사로 바꾼다. 배열은 이어 붙이지 않고 통째로 바꾼다.
