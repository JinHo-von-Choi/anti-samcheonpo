# solve(req) 구간 차집합 규칙

입력은 `{"base": [[a, b], ...], "cut": [[a, b], ...]}`이며 a, b는 정수다. 모든 구간은 반열린 구간 [a, b)다.

1. a >= b인 구간은 비어 있으므로 무시한다.
2. base와 cut은 정렬돼 있지 않고 서로 겹칠 수 있다.
3. 결과는 base의 합집합에서 cut의 합집합을 뺀 집합이다.
4. 결과는 시작점 오름차순의 서로소 구간 목록 `[[a, b], ...]`이며, 맞닿은 구간(예: [1, 3)과 [3, 5))은 하나로 합친다. 빈 결과는 `[]`다.
5. 입력 객체를 바꾸지 않는다.
